# AutoProfit – strona internetowa

Strona agencji ubezpieczeniowej **AutoProfit Barbara Jelonkiewicz** (Radom, na rynku od 2000 r.).

- `index.html` – cała strona (HTML + CSS + JS w jednym pliku)
- Hosting: GitHub Pages z gałęzi `main`

Formularz kontaktowy wymaga podłączenia backendu (np. skrypt PHP lub usługa typu Formspree), aby wysyłał wiadomości.
